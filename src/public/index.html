⚡ REST API Developer Gateway

WhatsFlow provides a high-performance REST API allowing you to send WhatsApp messages from any backend (Python, Node, PHP, Go, Curl).

1. Send Single Message (POST /api/v1/send-message)

curl -X POST http://localhost:3000/api/v1/send-message \ -H "Content-Type: application/json" \ -H "x-api-key: wf_live_your_generated_key_here" \ -d '{ "to": "9876543210", "message": "Hello from WhatsFlow REST API!" }'

2. Schedule Future Message (POST /api/v1/scheduled)

curl -X POST http://localhost:3000/api/v1/scheduled \ -H "Content-Type: application/json" \ -H "x-api-key: wf_live_your_generated_key_here" \ -d '{ "to": "9876543210", "message": "Reminder: Meeting tomorrow at 10 AM", "scheduledAt": "2026-10-03T10:00:00Z" }'
